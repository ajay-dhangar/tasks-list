# TaskFlow — Smart To-Do Manager

A modern, responsive task management application built with HTML, CSS and Vanilla JavaScript.

## Features

- Create, edit and delete tasks.
- Complete and reopen tasks.
- Individual task detail pages.
- Step-by-step checklist management.
- Automatic task progress tracking.
- Task priorities and categories.
- Due dates and overdue detection.
- Search and sorting.
- All, active, completed and overdue filters.
- Dark, light and system themes.
- Five accent color themes.
- LocalStorage persistence.
- JSON export and import.
- Responsive desktop, tablet and mobile design.
- Animated empty state and toast notifications.
- Keyboard shortcuts.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API
- Browser Dialogs and File API

## Installation

1. Clone or download this repository.
2. Open the project in VS Code.
3. Open `index.html` using Live Server.
4. Start managing your tasks!

No npm installation or backend is required.

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| Ctrl + N | Create new task |
| Ctrl + K | Search tasks |
| Escape | Close dialog |

On macOS, use Command instead of Ctrl.

## Data Storage

TaskFlow saves your tasks and preferences in browser LocalStorage.

Use Export Data to download your backup as JSON.

Import Data allows you to restore a previously exported backup. Importing replaces the existing task list after confirmation.

Clearing browser site data can erase saved tasks, so keep backups.
