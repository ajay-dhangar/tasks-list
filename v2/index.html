Install Tasks List App

Install Tasks List directly onto your device home screen or desktop for offline access and a native full-screen app experience:

📱 iOS (iPhone & iPad — Safari)

Tap the Share icon (square with upward arrow) at the bottom/top of Safari, scroll down, and tap "Add to Home Screen".

🤖 Android (Chrome / Edge / Brave)

Tap the ⋮ Menu in the top-right corner and select "Install app" or "Add to Home screen".

💻 Windows & macOS (Chrome / Edge)

Click the Install icon in the right side of your browser's address bar, or open Menu → Save and share → Install Tasks List.
